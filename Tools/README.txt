PC Plus 360 - Portable Tools Folder Structure
=============================================
PC Plus Computing | 604-760-1662 | 236-500-2700

HOW TO ADD TOOLS:
Download the portable version of each tool, EXTRACT it if it comes
as a ZIP, and place the .exe file in the matching category folder below.

The launcher scans all subfolders automatically - just drop the exe files in.

NIRSOFT (for NirSoft Suite launcher)
------------------------------------
  Place NirSoft .exe files here. The NirSoft Suite launcher
  (PCPlus-NirSoftSuite.ps1) scans this folder automatically.


NOTES:
- The launcher searches ALL subfolders up to 3 levels deep
- You can also put exe files directly in the Tools folder (unsorted)
- Most Sysinternals tools: https://learn.microsoft.com/en-us/sysinternals/downloads/
- NirSoft tools: https://www.nirsoft.net/utils/
- Tools do NOT need to be installed - just drop the portable exe files in
